Build the core database schema in packages/db using Drizzle, following
.cursor/rules/project.mdc. Schema and seed only — no business logic yet
(the inventory ledger logic comes in the next step).

Conventions for every table:
- Primary key: uuid, generated in the app as UUIDv7 (use the `uuid` package's v7).
- created_at / updated_at as timestamptz, defaulting to now(). updated_at set by the app on update.
- Every tenant-owned table has a non-null seller_id FK, indexed.
- Foreign keys use ON DELETE RESTRICT unless stated otherwise.
- Money: integer paise (bigint where totals could get large). GST rate in basis points (1800 = 18%).
- Use Postgres enums (pgEnum) for the status fields below.
- Split schema into files by domain (sellers, catalog, channels, inventory, orders, sync)
  and re-export from one index.

Enums:
- marketplace: amazon, flipkart, meesho, ajio
- channel_account_status: pending_onboarding, pending_auth, active, token_expired, suspended, disconnected
- integration_mode: api, file
- product_status: draft, active, archived
- listing_status: draft, validation_failed, ready, submitting, pending_review, live, rejected, paused, delisted, error
- movement_reason: initial, receive, adjustment, sale, cancellation, return_restock, return_damaged, transfer_in, transfer_out
- order_status: created, confirmed, packed, shipped, delivered, cancelled, returned, unknown
- return_status: requested, approved, in_transit, received, closed, rejected
- sync_run_type: listing_publish, stock_push, price_push, order_ingest, return_ingest, token_refresh
- sync_run_status: queued, running, succeeded, partially_failed, failed

Tables:

1. sellers — id, display_name, legal_name, gstin (nullable), status (active/suspended as text or enum),
   timestamps.

2. stock_locations — id, seller_id, name, is_default (boolean), address jsonb (nullable), timestamps.
   Partial unique index: one is_default=true per seller.

3. channel_accounts — id, seller_id, marketplace, external_seller_id (nullable until connected),
   status, integration_mode, token_secret_ref (text, nullable — a REFERENCE to a secret,
   never the token itself; add a comment saying so), token_expires_at, default_safety_buffer
   (int, default 0), settings jsonb default '{}', last_synced_at, timestamps.
   Unique (seller_id, marketplace, external_seller_id).

4. products — id, seller_id, title, description, brand, hsn_code, gst_rate_bps, country_of_origin,
   attributes jsonb default '{}', status, deleted_at (soft delete), timestamps.

5. variants — id, product_id, seller_id (denormalised for tenancy queries), sku, gtin (nullable),
   mrp_paise, selling_price_paise, weight_grams, length_mm, width_mm, height_mm,
   attributes jsonb (e.g. size, colour), status, deleted_at, timestamps.
   Unique (seller_id, sku). Check constraint: selling_price_paise <= mrp_paise.

6. product_images — id, seller_id, product_id, variant_id (nullable), s3_key, position,
   width, height, timestamps. Index (product_id, position).

7. channel_listings — id, seller_id, variant_id, channel_account_id, status,
   external_product_id (ASIN/FSN etc, nullable), external_listing_id (nullable),
   channel_category_id (nullable), channel_attributes jsonb default '{}' (per-channel overrides),
   price_override_paise (nullable), safety_buffer_override (nullable int),
   last_pushed_quantity (nullable int), last_pushed_price_paise (nullable),
   last_error jsonb (nullable), last_synced_at, timestamps.
   Unique (variant_id, channel_account_id). Index (channel_account_id, status).

8. channel_listing_events — append-only audit: id, seller_id, channel_listing_id,
   from_status, to_status, message, details jsonb, created_at. Index (channel_listing_id, created_at).

9. inventory_movements — append-only ledger: id, seller_id, variant_id, location_id,
   quantity_delta (int, check <> 0), reason, source_type (text: manual, order, return, import, system),
   source_ref (text, nullable — e.g. order line id), idempotency_key (text, UNIQUE, not null),
   note (nullable), created_by (nullable text for now — users come later), created_at.
   Index (variant_id, location_id, created_at).

10. inventory_levels — current balance cache: seller_id, variant_id, location_id, on_hand (int),
    version (int, default 0), updated_at. Primary key (variant_id, location_id).
    Add a comment: "Derived from inventory_movements; only written inside the ledger transaction."

11. orders — id, seller_id, channel_account_id, marketplace, external_order_id, status,
    raw_status (text), ordered_at, total_paise (bigint), currency (default 'INR'),
    payload jsonb (nullable), timestamps.
    Unique (channel_account_id, external_order_id). Index (seller_id, ordered_at desc).
    IMPORTANT comment: payload must have buyer PII (name, address, phone, email) stripped
    before storage. Do not add any buyer PII columns.

12. order_lines — id, seller_id, order_id, external_line_id, external_sku, variant_id
    (nullable — null means unmapped SKU), quantity, unit_price_paise, status, timestamps.
    Unique (order_id, external_line_id). Index (variant_id).

13. returns — id, seller_id, channel_account_id, order_id, order_line_id (nullable),
    external_return_id, status, quantity, reason (text), restocked (boolean default false),
    timestamps. Unique (channel_account_id, external_return_id).

14. sync_runs — id, seller_id, channel_account_id (nullable), type, status, bullmq_job_id
    (nullable), items_total, items_succeeded, items_failed, error jsonb (nullable),
    started_at, finished_at, created_at. Index (seller_id, created_at desc).
